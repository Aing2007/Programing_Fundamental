# โจทย์เขียนโปรแกรมภาษา C: อ่านข้อมูลจากไฟล์ .dat มากกว่า 2 ไฟล์

## ชื่อโจทย์: Student Performance Report

**ระดับ:** พื้นฐาน–ปานกลาง  
**หัวข้อที่วัด:** `struct`, array of structures, pointer, function, การอ่านไฟล์ด้วย `fopen()` / `fscanf()` / `fclose()`

### สถานการณ์

อาจารย์มีข้อมูลนักศึกษาแยกเก็บไว้ในไฟล์ 3 ไฟล์ ได้แก่

1. `students.dat` เก็บรหัสและชื่อของนักศึกษา
2. `scores.dat` เก็บคะแนนสอบของนักศึกษา
3. `attendance.dat` เก็บจำนวนครั้งที่เข้าเรียนและจำนวนครั้งที่เข้าเรียนทั้งหมด

จงเขียนโปรแกรมภาษา C เพื่ออ่านข้อมูลจากไฟล์ทั้ง 3 ไฟล์ แล้วนำข้อมูลมาเชื่อมโยงกันด้วย **รหัสนักศึกษา (Student ID)** ก่อนแสดงรายงานผล

> ไฟล์ `.dat` ในข้อนี้เป็นไฟล์ข้อความ (text file) ไม่ใช่ไฟล์ไบนารี สามารถเปิดอ่านด้วย `fscanf()` ได้

### รูปแบบข้อมูลในไฟล์

**1) `students.dat`**

แต่ละบรรทัดเก็บ `รหัสนักศึกษา ชื่อ`

```text
65001 Anan
65002 Benja
65003 Chai
65004 Dara
65005 Ekachai
```

**2) `scores.dat`**

แต่ละบรรทัดเก็บ `รหัสนักศึกษา คะแนนเก็บ คะแนนกลางภาค คะแนนปลายภาค`

```text
65003 18 25 42
65001 15 20 38
65005 20 28 45
65002 12 18 30
65004 17 22 40
```

**3) `attendance.dat`**

แต่ละบรรทัดเก็บ `รหัสนักศึกษา จำนวนครั้งที่เข้าเรียน จำนวนครั้งที่มีการเรียนทั้งหมด`

```text
65002 18 20
65004 16 20
65001 20 20
65005 19 20
65003 14 20
```

หมายเหตุ: ลำดับข้อมูลในแต่ละไฟล์ไม่เหมือนกัน โปรแกรมจึงห้ามนำข้อมูลบรรทัดที่ 1 ของทุกไฟล์มาจับคู่กันโดยตรง ต้องใช้รหัสนักศึกษาในการค้นหาข้อมูลที่ตรงกัน

### สิ่งที่โปรแกรมต้องทำ

1. ประกาศ `struct Student` เพื่อเก็บข้อมูลนักศึกษาอย่างน้อยดังนี้
   - รหัสนักศึกษา
   - ชื่อ
   - คะแนนเก็บ
   - คะแนนกลางภาค
   - คะแนนปลายภาค
   - จำนวนครั้งที่เข้าเรียน
   - จำนวนครั้งที่มีการเรียนทั้งหมด
2. อ่านข้อมูลจากไฟล์ทั้ง 3 ไฟล์ โดยใช้ `fopen()` และตรวจสอบว่าเปิดไฟล์สำเร็จหรือไม่
3. เก็บข้อมูลลงใน array ของ structure
4. จับคู่ข้อมูลจากทั้ง 3 ไฟล์ด้วยรหัสนักศึกษา
5. คำนวณคะแนนรวม โดยใช้สูตร

   `คะแนนรวม = คะแนนเก็บ + คะแนนกลางภาค + คะแนนปลายภาค`

6. คำนวณเปอร์เซ็นต์การเข้าเรียน โดยใช้สูตร

   `เปอร์เซ็นต์เข้าเรียน = (จำนวนครั้งที่เข้าเรียน / จำนวนครั้งที่มีการเรียนทั้งหมด) * 100`

7. แสดงรายงานนักศึกษาทุกคน โดยเรียงตามรหัสนักศึกษาจากน้อยไปมาก

### รูปแบบผลลัพธ์ที่ต้องการ

ตัวอย่างรูปแบบการแสดงผล (ตัวเลขและข้อมูลต้องคำนวณจากไฟล์จริง)

```text
========== STUDENT PERFORMANCE REPORT ==========
ID      Name       Total Score    Attendance
------------------------------------------------
65001   Anan       73             100.00%
65002   Benja      60             90.00%
...
------------------------------------------------
Total students: 5
Average score: xx.xx
================================================
```

### เงื่อนไขและข้อกำหนด

- ต้องใช้ `struct` ในการจัดเก็บข้อมูล
- ต้องอ่านข้อมูลจากไฟล์ `.dat` ทั้ง 3 ไฟล์จริง ห้ามเขียนข้อมูลนักศึกษาลงในโค้ดโดยตรง
- ต้องเปิดไฟล์ทั้ง 3 ไฟล์และตรวจสอบข้อผิดพลาดจากการเปิดไฟล์
- ต้องปิดไฟล์ทุกไฟล์ด้วย `fclose()` เมื่อใช้งานเสร็จ
- ต้องจับคู่ข้อมูลด้วยรหัสนักศึกษา ไม่ใช่ลำดับบรรทัด
- สามารถแยกการทำงานเป็นฟังก์ชันได้ เช่น `ReadStudents()`, `ReadScores()`, `ReadAttendance()` และ `DisplayReport()`
- กำหนดจำนวนข้อมูลสูงสุดได้เอง แต่ต้องรองรับข้อมูลตัวอย่างทั้ง 5 คน

### สิ่งที่ต้องส่ง

1. ไฟล์ source code นามสกุล `.c`
2. ไฟล์ `.dat` ทั้ง 3 ไฟล์
3. ภาพหน้าจอผลลัพธ์การทำงาน

**ข้อห้าม:** ห้ามแก้ไขไฟล์ข้อมูลตัวอย่างเพื่อให้ตรงกับลำดับข้อมูลของไฟล์อื่น และห้ามใช้ข้อมูลที่ hardcode อยู่ในโปรแกรมแทนการอ่านไฟล์
